# Tier 4 - Database

The tables and their fields. Each folder is a Django app (`apps.py`); its label (`devices`, `backups` ...)
never changes, so table names and migration history stay the same.

| File / folder | Main job |
|---|---|
| `<app>/models.py` | Tables and fields |
| `<app>/migrations/` | Database changes, generated by `python manage.py makemigrations` (never edit by hand) |
| `<app>/apps.py` | Django app registration (`name = "database.<app>"`, fixed `label`) |
| `<app>/admin.py` | Django admin pages |

Rules: uses only `core`; never another tier.

## The apps

| App | What it does |
|---|---|
| `accounts` | Portal users, sign-in, lockout, roles |
| `devices` | Device inventory and saved logins |
| `backups` | Configuration backups, versions, change reports, audit trail |
| `monitoring` | Ping monitor, Dashboard numbers, server health |
| `scheduling` | Settings and the automatic backup timer |
| `radius` | FreeRADIUS users, levels, NAS clients, Authentication Audit |
| `commandlog` | Session Log: who ran which command on which device |
